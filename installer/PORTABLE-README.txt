vibranceGUIx
Digital Vibrance for Windows
https://github.com/M-ax/vibranceGUIx

GET STARTED
1. Extract the entire portable ZIP to a folder you intend to keep.
2. Keep vibrance.GUI.exe, its .config file and the DLL together.
3. Run vibrance.GUI.exe. Windows 10/11 and .NET Framework 4.8+ are required.
4. Leave Graphics driver on Auto (prefer NVIDIA) for NVIDIA + Radeon iGPU PCs.
5. Add a running game or choose its executable with Add manually.
6. Set a desktop baseline and an in-game color level, then save the game profile.
7. Use Never change resolutions if you only want color adjustments.

STARTUP AND GPU SELECTION
Launch on boot is optional and starts the app minimized at Windows sign-in.
GPU preference changes take effect after exiting from the tray and reopening.
If you move the portable folder, check Launch on boot again to update its path.
Only displays connected to the selected GPU can be controlled.

UPGRADING
Exit the running app from the tray before replacing its files.
Settings remain in %AppData%\vibranceGUI for compatibility with earlier builds.
The executable name is intentionally still vibrance.GUI.exe.
Do not run vibranceGUI and vibranceGUIx at the same time.
